# FastAPI Boilerplate

A production-ready FastAPI boilerplate with PostgreSQL, Redis, Alembic migrations, and modern Python tooling.

## Roadmap

### 1. Done

- [x] IDE formatting (editorconfig)
- [x] Runtime environment management (mise)
- [x] Package management (uv)
- [x] Version control (git, pre-commit)
- [x] Containerization (Docker, Docker Compose)
- [x] Task management (Taskfile)
- [x] Code analysis (ruff)
- [x] Type checking (mypy)
- [x] Security (CORS)
- [x] Logging (structlog)
- [x] Database (PostgreSQL, SQLAlchemy)
- [x] Migration (Alembic)
- [x] Caching (Redis)
- [x] Documentation (OpenAPI, Swagger UI)

### 2. In Progress

- [ ] Validation (Pydantic)
- [ ] Internationalization (i18n)
- [ ] Pagination (Limit-Offset, Cursor-Based)
- [ ] Sorting (Multiple-Sort)
- [ ] Filtering (Multiple-Filter)
- [ ] Searching (Full-Text Search)
- [ ] Testing (pytest, pytest-cov)
- [ ] Benchmarking (pytest-benchmark)
- [ ] Performance testing (jmeter)
- [ ] Security testing (bandit)
- [ ] Usability testing (selenium)
- [ ] Accessibility testing (axe-core)
