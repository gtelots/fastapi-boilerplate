# FastAPI Boilerplate

A production-ready FastAPI boilerplate with PostgreSQL, Redis, Alembic migrations, and modern Python tooling.

## Features

- ⚡ **FastAPI** - Modern, fast web framework for building APIs
- 🗄️ **PostgreSQL** - Powerful, open-source relational database
- 🔄 **Alembic** - Database migration tool
- 📦 **Redis** - In-memory data structure store for caching
- 🐳 **Docker** - Containerization with Docker Compose
- 🔧 **mise** - Development environment manager (Python + uv version management)
- 📝 **uv** - Fast Python package manager
- 🧪 **pytest** - Testing framework with async support
- 📊 **Structured Logging** - Using structlog
- 🔍 **Type Checking** - mypy for static type analysis
- 🎨 **Code Formatting** - ruff for linting and formatting
- 📈 **Monitoring** - Sentry, PostHog, and Logfire integration ready
- 🔐 **Security** - Best practices for production deployment
